1. Pyroscope установлен успешно!

2. Получить доступ к Pyroscope:
   Из кластера (для приложения):
     http://{{ include "pyroscope.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

   Из хоста (port-forward):
     kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "pyroscope.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
     http://localhost:{{ .Values.service.port }}

3. Включить профилирование в приложении:
   task app-pyroscope-enable

4. Проверить статус:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "pyroscope.name" . }}
   kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "pyroscope.name" . }} -f

5. Отключить профилирование:
   task app-pyroscope-disable
   
6. Удалить Pyroscope:
   task pyroscope-down
